# Contributing to Attus

Obrigado por considerar contribuir para o projeto Attus! Este documento descreve as diretrizes para contribuições.

## Como Contribuir

### Reportar Bugs

- Verifique se o bug já não foi reportado
- Inclua o máximo de detalhes possível:
  - Versão do sistema operacional
  - Versão do Java/Node.js
  - Steps para reproduzir
  - Comportamento esperado
  - Comportamento atual
  - Logs (se disponível)

### Sugerir Melhorias

- Use um título claro e descritivo
- Forneça uma descrição detalhada
- Liste exemplos específicos para demonstrar os passos
- Descreva o comportamento atual e esperado

### Pull Requests

1. **Fork** o repositório
2. **Clone** seu fork: `git clone https://github.com/YOUR_USERNAME/attus.git`
3. **Crie uma branch** para sua feature: `git checkout -b feature/amazing-feature`
4. **Commit** suas mudanças: `git commit -m 'Add amazing feature'`
5. **Push** para a branch: `git push origin feature/amazing-feature`
6. **Abra um Pull Request**

## Padrões de Código

### Java/Spring Boot
- Seguir convenções Java (CamelCase)
- Usar Lombok para reduzir boilerplate
- Adicionar Javadoc para métodos públicos
- Manter cobertura de testes acima de 80%

### TypeScript/Angular
- Usar strict mode (`strict: true`)
- Adicionar tipos onde não inferidos
- Usar pipe async quando possível
- Manter componentes reutilizáveis

### Geral
- Código legível > código clever
- Documentar decisões não óbvias
- Respeitar padrões existentes
- Não incluir dependências desnecessárias

## Processo de Review

1. Seu PR será revisado por maintainers
2. Pode ser solicitadas mudanças
3. Uma vez aprovado, será feito merge
4. Você será creditado nos release notes

## Código de Conduta

- Sê respeitoso com todos
- Sê acolhedor com novatos
- Critica ideias, não pessoas
- Respeita privacidade

## Dúvidas?

- Abra uma issue com tag `question`
- Participe das discussões
- Consulte a documentação
